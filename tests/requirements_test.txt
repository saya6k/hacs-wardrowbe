# pytest-homeassistant-custom-component pulls in pytest, pytest-asyncio,
# and the rest of the test toolchain at the exact versions Home Assistant
# core uses. Don't add separate pins for pytest / pytest-asyncio here —
# the resolver will pick a stale version that conflicts with the HA-aligned
# pin chosen by this package, and you'll end up with the
# `pytest>=8 vs pytest-asyncio<8` deadlock.
#
# Must match the devcontainer image tag (.devcontainer/devcontainer.json) —
# one version string across both, now that 2026.8.0b0 has shipped and
# hacs.json's end-user-facing floor, the image and this pin all read the same
# release. Inside the devcontainer `homeassistant` is satisfied by the image's
# preinstalled copy; phacc still pins homeassistant==2026.7.x, so a clean
# resolve outside the image can't satisfy both (unchanged from the nightly
# pin) and tests/conftest.py keeps its phacc compat shim.
pytest-homeassistant-custom-component>=0.13.346
homeassistant>=2026.8.0b0
